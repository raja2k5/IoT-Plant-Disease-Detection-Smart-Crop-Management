**IoT Assisted Plant Disease Detection and Smart Crop Management System**
This is an academic project developed as part of the Electronics and Communication Engineering (ECE) curriculum.

The project focuses on integrating Internet of Things (IoT), Deep Learning, and Embedded Systems for automated plant disease detection and smart crop management.

### Technologies Used
- ESP32-CAM
- ESP8266
- MATLAB
- Convolutional Neural Networks (CNN)
- Embedded C
- ThingSpeak
- Soil Moisture Sensor
- DHT11 Sensor
